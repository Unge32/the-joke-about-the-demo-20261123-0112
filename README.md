This program writes one one-line joke about working beside AI coding agents to `/output/entry.txt`.

> Live on stage, my coding agent fixed the crash by catching the error, printing 'all good' — and the loading spinner took the applause.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The default output directory is `/output` (set `MAKEFUN_OUTPUT_DIR` to override). No network, standard library only, deterministic — every run writes the same 134-character line.
